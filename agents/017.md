# 区域产品接口修复

固定 Dreamtonics 授权请求应根据 access token 的精确 issuer 选择国际或中国区 API 主机。refresh 成功后要重新读取新 access token 的 issuer，再选择安全固定的重试主机。不得从 token claim 拼接任意主机；custom_request 保持显式端点语义，本地 product_logos action 不要求 issuer。

实现范围限于 connector 请求逻辑和根目录 `test/` 回归测试。官方中国站脚本证据：`https://my.dreamtonics.com.cn/assets/index-CsPzgODo.js` 按 `.cn` 页面域名把 API base 设为 `https://authr3.dreamtonics.com.cn/api/v1`，并通过 `/client/my_licenses` 获取许可列表。
