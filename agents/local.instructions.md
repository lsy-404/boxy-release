# 此项目指令

- 公开GitHub Release说明仅写“改进了一些内容”，不附加功能介绍、技术变更清单或自动生成的发行日志。
- main 每次推送后由 Action 将相同文件树归一化为单个无父、无签名提交；保留源提交的作者与提交者身份，二者时间均为 1970-01-01T00:00:00Z。仅在远端仍等于本次预期提交时使用带精确 lease 的强制推送。
- 普通发行包不内置或预填服务URL。没有用户明确指定的地址时，先显示空白的本地地址选择页；确认后才解析本机会话并连接服务，不持久保存所选地址。
