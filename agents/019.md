# 区域图片许可证查询修复

产品图片补全在本地 metadata/cache 未覆盖请求 key 时会读取 `my_licenses`。此按需许可证读取应复用 connector 的固定 issuer 到区域 API base 映射，仅将 token 发往对应固定 endpoint。空 key 或本地缓存已覆盖时保持纯本地成功，无需解析 issuer。

实现范围限于图片补全许可证查询路径及根目录 `test/` 回归测试。使用已验证的 Dreamtonics 中国 API host `https://authr3.dreamtonics.com.cn`，不从 token claim 构造 hostname。
