# 系统浏览器启动决策

## 动机

Windows 公开 v2.0.5 使用 Wry/Tao 内嵌 WebView2 显示 connector UI。未显式指定 WebView2 用户数据目录时，Runtime 会在 executable 旁创建 `<executable>.WebView2`。用户要求移除 WebView2，并只在服务成功创建授权操作且返回经校验的 browser URL 后通过系统浏览器打开页面。

## 决策

- 删除 Wry/Tao 窗口、内嵌 HTML、IPC 与专属 UI 资源及依赖；不保留兼容 UI。
- 保留既有 connector 操作请求、浏览器 URL 校验、session 变化监视、签名回执和任务执行。
- 继续支持 `--server`、`--session` 和从可识别文件名推断服务地址；普通发行文件名使用当前 Boxy 服务默认地址。
- session 路径使用默认值，缺失时通过现有 `rfd` 文件选择器选择；错误继续使用原生消息框。
- 连接器继续按现有服务端操作状态监视 session；不新增托盘、事件循环或本地 HTTP 服务。
- smoke 测试只使用 loopback HTTP stub 和假 session，检查创建操作后系统浏览器到达授权 URL，并确认 connector executable 旁没有 WebView2 目录。

## 范围

只修改 boxy-release connector 与其根目录 `/test` 验证、发行构建相关配置及本任务审计记录。不改 Worker、版本号、发布资产或远程状态。
