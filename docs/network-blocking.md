# SV2 网络屏蔽与高级主机选择

## 目标

Boxy 在 macOS 和 Windows 上切换 hosts 屏蔽时，写入成功后立即刷新系统解析缓存。网络卡片提供按需读取 SV2 内嵌浏览器请求缓存的高级选项，让用户逐项选择额外主机。缓存记录仅用于候选列表，不自动加入屏蔽规则。

## 切换与状态

- 标准屏蔽继续管理已确认的 Dreamtonics 主机，并同时写入 IPv4 和 IPv6 条目。
- macOS 写入后刷新目录服务解析缓存；Windows 在提权写入后执行 `ipconfig /flushdns`。未改动 hosts 时无需重复刷新。
- 若 hosts 已改而刷新失败，界面必须明确显示部分成功及本机实际规则状态，不能显示操作完成。
- 页面等待连接器回传任务结果，再更新屏蔽状态；排队成功不等于切换完成。新会话需要从连接器读取当前本机状态。
- 关闭屏蔽时只移除 Boxy 管理的条目，包括用户勾选的附加主机，不触碰其他 hosts 内容。

## 浏览器请求记录

- macOS 从 SV2 专属 WebKit NetworkCache 的请求记录读取主机。Windows 从 SV2 的 `%APPDATA%\Dreamtonics\Synthesizer V Studio 2\webview2` 目录读取 WebView2 缓存请求键。
- 仅接受缓存记录头中的请求 URL；网页正文、证书资料、替代服务公告和仅在程序二进制中出现的 URL 不算已发生的请求。
- 扫描只读且有文件数量与读取字节上限。发送到网页的结果仅包含规范化主机名、记录数量、最近缓存时间和来源；不传 URL 路径、查询参数、Cookie、响应正文或授权资料。
- 缓存可能被清除、过期或只覆盖部分请求。列表必须标明这是历史缓存，不能声称列出 SV2 的全部联网目标。

## 高级选项

- 用户主动点击“列出浏览器缓存主机”后才扫描。标准名单中的主机显示为已包含；其他主机默认不勾选。
- 勾选附加主机前提示：hosts 是整机规则，会影响其他应用和网页。已屏蔽时也可以单独应用新的勾选结果。
- 附加主机必须来自本机扫描结果或当前已由 Boxy 管理的附加条目；限制数量并拒绝无效域名、本地地址及 Boxy 服务主机。云端和提权写入端都要验证输入。
- 如果某平台没有可验证的缓存格式或缓存目录，显示“没有可用记录”，仍允许使用标准屏蔽。

## 验收

- macOS 和 Windows 的启用、更新勾选、关闭三个流程均确认 hosts 内容、解析缓存刷新结果和界面最终状态。
- 使用包含请求键与网页正文 URL 的缓存样本验证不会把正文链接误列为连接记录。
- 验证附加主机不会自动勾选，取消勾选或关闭屏蔽后其 Boxy 条目被精确移除；其他 hosts 条目保持不变。
- 在真实 Windows SV2 安装上核对 WebView2 缓存路径和解析结果；没有该证据时只报告代码与样本验证范围。
