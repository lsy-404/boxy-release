# SV2 网络屏蔽

浏览器发起状态读取或切换任务后，由本地客户端执行并回传结果。任务排队成功不代表规则已经生效。

## Hosts 模式

Windows 和 macOS 客户端在系统 hosts 文件中管理连接器列出的 Dreamtonics 主机名。状态显示已处理的主机条目数和规则标记；它不表示其他域名、IP 地址、子进程或联网目标都已屏蔽。

## Windows Firewall 模式

除 hosts 条目外，客户端还会为已定位的 SV2 可执行文件添加出站规则。状态包括规则是否存在、是否在活动防火墙配置中生效，以及防火墙配置文件状态。若客户端无法查询防火墙，就不会把解除操作报告为成功。该规则只针对该可执行文件，不代表设备完全离线。

旧版 2.0.0 客户端创建的 WFP 过滤器是持久规则；当前客户端不会检测或移除它们。升级前请用 2.0.0 客户端解除旧规则。如果已经升级，可暂时恢复 2.0.0 客户端并使用其解除操作，再继续使用当前客户端。

## LuLu

Boxy 无法通过受支持的接口读取或更改 LuLu 规则，也不会安装 LuLu 或生成导入文件。用户可以直接在 LuLu 中管理规则；Boxy 无法验证这些规则是否生效。
